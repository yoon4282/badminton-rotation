# 🏸 배드민턴 대진표 & 코트 로테이션

백엔드·DB·외부 API 없이 브라우저에서만 동작하는 모바일 웹앱입니다. 모든 데이터는 localStorage에 자동 저장됩니다.

## 로컬 실행
ES Modules를 쓰므로 `file://`로는 열리지 않습니다. 간이 서버를 사용하세요.

```bash
python -m http.server 8080
```
→ http://localhost:8080

## QR 참가자 등록 (PeerJS)
- 운영진 화면 `📱 QR 초대 코드 열기` → QR 모달. 참가자가 QR을 찍으면 `?join=방ID` 화면이 열리고, 이름·성별·급수를 보내면 운영진 명단에 즉시 추가됩니다.
- PeerJS(무료 클라우드 브로커)와 qrcodejs는 CDN에서 **버튼을 누를 때만** 불러옵니다. 로드·연결에 실패해도 직접 입력/일괄 추가에는 영향이 없습니다.
- 데이터는 서버에 저장되지 않고 브라우저 간에만 전달됩니다. 운영진 창(탭)이 열려 있어야 등록할 수 있습니다.
- 휴대폰으로 스캔하려면 `localhost`가 아닌 배포된 주소(https)에서 QR을 열어야 합니다.
- 학교 와이파이·핫스팟처럼 기기끼리 직접 연결이 막히는 곳에서는 TURN 중계 서버(Metered Open Relay 무료 플랜, 월 20GB, 443/TLS 지원)를 거칩니다. 설정은 `js/config.js`의 `ICE_SERVERS`, 사용량은 Metered 대시보드에서 확인하세요.

## 부 관리자 연동
- 메인 관리자 화면 `👥 부 관리자 초대` → QR/링크(`?admin=방ID&key=비밀키`)를 운영진에게 보내면, 같은 명단·대진·결과를 보면서 결과 입력·참가자 추가·휴식 전환·다음 라운드·다시 짜기를 함께 할 수 있습니다. 부 관리자 화면의 참가자 QR은 메인 관리자 명단으로 등록돼요.
- 상태의 주인은 **메인 관리자 기기**입니다. 부 관리자는 조작 요청만 보내고, 메인이 반영한 전체 상태를 모두에게 다시 보내요(`js/admin.js`, `js/p2p.js`의 `createAdminClient`). 부 관리자 기기에는 저장하지 않습니다.
- 두 사람이 동시에 `다음 라운드`를 눌러도 라운드가 두 번 생기지 않고, 그사이 대진이 바뀌었으면 결과 입력을 거절합니다.
- `전체 초기화`·`새 경기 시작`은 메인만 할 수 있어요. `🔒 링크 새로 만들기`를 누르면 기존 부 관리자는 끊기고 예전 링크는 못 씁니다.
- 메인 관리자 화면(탭)이 열려 있어야 합니다. 한 번 초대를 켠 기기는 새로고침해도 같은 방 ID로 자동 재연결되어 부 관리자도 다시 붙습니다.

## 카톡 투표 참여자 옮기기 (회원 기억)
- 카톡 투표의 참여자 이름을 `여러 명 한 번에 붙여넣기`에 적으면 됩니다. `김철수, 이영희, 박민수`처럼 쉼표·띄어쓰기·줄바꿈 아무거나로 구분해요.
- 한 번 등록한 사람(직접 추가·붙여넣기·QR 모두)은 성별·급수를 이 기기에 기억해 두었다가, 다음 모임에서 **이름만 적어도** 자동으로 채웁니다. 직접 입력 칸에 이름을 쳐도 성별·급수 버튼이 자동 선택돼요.
- 목록에서 급수·성별을 바꾸면 기억도 함께 바뀝니다. `전체 초기화`를 해도 회원 기억은 지워지지 않습니다(`js/roster.js`, localStorage `badminton-members-v1`).

## 🔗 같이 치기 요청
- 참가자 탭 `🔗 같이 치기` → `같이 치고 싶은 사람 고르기`에서 종류와 반복을 고르고 사람을 누른 뒤 `요청 추가`.
  - **같은 편**(2명): 한 팀으로 · **같은 코트**(2명): 편이든 상대든 한 코트에 · **한 코트**(4명): 4명이 한 코트, 팀은 돌아가며 바뀜
  - **1️⃣ 다음 판 한 번**: 들어주면 목록에서 사라져요. 못 들어주면 다음 판에 다시 시도합니다. `다시 짜기`를 하면 되돌려서 다시 반영해요.
  - **🔁 계속**: 매 라운드 같이 넣어요. 목록의 `한 번/계속` 버튼으로 언제든 바꿀 수 있어요.
- 대진에서 요청대로 모인 코트에는 `🔗 같이` 표시가 붙어요. 부 관리자도 요청을 추가·삭제할 수 있어요.
- **경기 수 공평이 우선**입니다. 둘 중 한 명만 쉴 차례면 경기 수가 같은 사람과 맞바꿔 같이 뛰거나 같이 쉬게 하고(지난 판에 쉰 사람은 또 쉬게 하지 않음), 그래도 안 되면 그 판은 넘깁니다. 예: 14명 3코트(2명 휴식)에서 4명 묶음은 넷이 한꺼번에 쉴 자리가 없어 가끔 갈라져요.
- 남복 vs 여복 금지는 그대로 지키고, 요청으로 모인 코트는 경기 유형 비율·개인 유형 쏠림 계산에서 빼요. 같이 치는 사이끼리는 파트너·상대 반복 벌점을 줄여 묶음이 유지돼요.
- 구현: `js/wishes.js`(요청 관리), `js/matcher.js`의 `fitWishes`(선발 맞교환)·`seedOrder`(코트 미리 모으기)·`WEIGHTS.wish`(요청 보너스).

## 투표 캡처로 추가 (글자 인식)
- `📷 투표 캡처로 추가` → 카톡 투표 **참여자 화면 캡처**를 고르면(여러 장 가능) 이름 후보가 나옵니다. 확인·수정 후 `선택한 n명 추가`.
- 기억된 회원은 미리 체크되고 성별·급수가 자동으로 채워집니다. 한 글자 틀리게 읽힌 이름(예: 박민스)은 회원 이름(박민수)으로 고쳐 보여 줘요.
- 글자 인식은 Tesseract.js로 **브라우저 안에서** 합니다(캡처는 서버로 보내지 않음). 처음 쓸 때 라이브러리와 한글 인식 데이터를 CDN에서 받습니다(수 MB, 이후 캐시).
- 이름 후보 추출 규칙은 `js/ocr-parse.js` (화면 문구 제외 목록 `STOP`).

## 카카오톡 바로 공유 설정
`💬 카톡으로 공유` 버튼을 누르면 카카오톡 채팅방 선택 화면이 바로 열리게 하려면 한 번만 설정하면 됩니다.
1. https://developers.kakao.com 로그인 → **내 애플리케이션 → 애플리케이션 추가하기**
2. **앱 키**에서 **JavaScript 키** 복사 → `js/config.js`의 `KAKAO_JS_KEY`에 붙여넣기
3. **플랫폼 → Web → 사이트 도메인**에 배포 주소 등록 (예: `https://아이디.github.io`, 로컬 테스트용 `http://localhost:8080`)

- 카톡 텍스트 메시지는 **200자까지**라, 넘으면 급수·유형을 뺀 짧은 버전으로 보냅니다. 그래도 길면(코트가 많을 때) 휴대폰 공유 창으로 넘어가요. 순위표는 들어가는 만큼만 보내고 "…외 n명"으로 줄입니다.
- 키를 비워 두거나 SDK를 불러오지 못하면 휴대폰 공유 창 → 복사 순서로 동작합니다.

## 구조
- `js/matcher.js` 대진 생성 (경기 수 우선 → 코트 편성 → 팀 분할, 비용 함수 가중치는 상단 `WEIGHTS`)
  - **남복 vs 여복은 만들지 않습니다**(남2·여2가 한 코트면 혼복 vs 혼복으로 나눔). 인원상 불가피할 때의 여복 vs 혼복, 남복 vs 혼복은 허용하되 최대한 피해요.
  - 경기 유형 목표 비율은 `TYPE_RATIO` (기본 남복:여복:혼복 = 3:2:1). 경기 수 공평이 우선이라, 성비상 불가능하면 가능한 범위에서 가장 가깝게 맞춥니다(예: 남6·여6 전원 출전이면 라운드마다 남복·여복·혼복 1개씩이 최선).
- `js/wishes.js` 같이 치기 요청(같은 편·같은 코트·4명 묶음 × 한 번·계속)
- `js/stats.js` 라운드 기록에서 전적/순위 계산
- `js/players.js` 참가자 추가·일괄 파싱·토글
- `js/share.js` 카카오톡 공유 텍스트·복사
- `js/ui.js`, `js/main.js` 렌더링과 이벤트
